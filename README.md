# Sweet Design Studio

> AI-powered creative toolkit for designers, content creators, and microstock contributors.

## Overview

Sweet Design Studio is a modern AI creative platform focused on simplifying digital design workflows.
The project is built to help creators generate design assets, prompts, branding ideas, creative layouts, and visual concepts faster using AI.

This ecosystem is specially designed for:

- Microstock contributors
- Content creators
- Social media designers
- AI artists
- Prompt engineers
- YouTube creators
- Freelancers

# Local Setup

## Prerequisites
- Node.js
- npm

## Installation

```bash
npm install
```

## Environment Setup

Create a `.env.local` file and add:

```env
GEMINI_API_KEY=your_api_key_here
```

## Run Development Server

```bash
npm run dev
```
